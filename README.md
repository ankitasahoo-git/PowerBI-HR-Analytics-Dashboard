# PowerBI-HR-Analytics-Dashboard

📌 Project Overview

This project is an interactive HR Analytics Dashboard built using Power BI to analyze employee attrition, salary distribution, age groups, job roles, and workforce insights.
The dashboard helps HR teams understand employee behavior and identify key factors affecting attrition.

🚀 Features
Employee Attrition Analysis
Attrition Rate Tracking
Department-wise Insights
Gender-based Attrition Analysis
Salary Slab Distribution
Age Group Analysis
Job Role Attrition Comparison
Years at Company Analysis
Interactive Visualizations & Filters

📊 Key Insights
Total Employees: 1470
Total Attrition: 237
Attrition Rate: 16.1%
Average Age: 37
Average Salary: 6.5K
Average Years at Company: 7.0

🛠️ Tools & Technologies Used
Power BI
Excel / CSV Dataset
Data Cleaning & Transformation
DAX Measures
Data Visualization

🎯 Purpose of the Project
The main objective of this project is to:

Analyze employee attrition trends
Improve HR decision-making
Identify high attrition areas
Support workforce planning through data insights

📌 Conclusion

This dashboard provides meaningful HR insights through interactive visualizations and helps organizations make data-driven decisions for employee retention and workforce management.
